# AgentVision — Linux dependencies (Artix / Arch and friends; any distro)
# Install with:  python3 -m pip install -r requirements-linux.txt
#
# SYSTEM packages (pacman names; full notes + init-system service templates
# in dist/linux/README.md):
#
#   Wayland capture : grim                      (wlroots compositors: Sway/
#                                                Hyprland/labwc — the common
#                                                Artix setups)
#                     xdg-desktop-portal + a backend for your compositor
#                     (xdg-desktop-portal-wlr / -gtk / -kde) — the portable
#                     portal fallback; needs `gdbus` from glib2 (usually
#                     already installed)
#   X11 CLI capture : maim  OR  scrot  OR  imagemagick — only needed if the
#                     python `mss` package is not installed
#   X11 window tools: xdotool and/or wmctrl — fallbacks when python-xlib is
#                     absent; xdotool also anchors the input daemon's
#                     absolute pointer position
#   Fonts           : ttf-dejavu (overlay stamp bar; /usr/share/fonts/TTF/)
#   Tk GUI          : tk (only for the desktop GUI; the bridge is headless)
#
#   Input recording : /dev/input/event* must be readable — add your user to
#                     the `input` group and re-login:
#                         sudo usermod -aG input $USER
#                     (The optional uinput injection self-test additionally
#                     needs writable /dev/uinput; skipping it is fine.)
#
