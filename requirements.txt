# ── On-screen text OCR (av_ocr_frame / av_read_screen) ──────────────────
# Reads UI text / error dialogs / stack traces out of a frame WITHOUT spending
# vision tokens (an error dialog as JSON ≈ 30 tokens vs ≈ 4800 as an image).
#
# NO SYSTEM INSTALL REQUIRED. macOS ships a first-class OCR engine inside the
# OS (Apple Vision / VNRecognizeTextRequest); the pyobjc binding below is a
# plain pip wheel, so OCR works out of the box after `pip install -r`.
# Measured on realistic UI text: identical accuracy to tesseract.
pyobjc-framework-Vision>=10.0
#
# tesseract is OPTIONAL and only a speed optimisation (~245 ms vs ~1100 ms per
# frame). AgentVision prefers it automatically IF the binary already exists
# (brew install tesseract) and silently uses Apple Vision otherwise.
pytesseract>=0.3.10
#
# Engine selection is automatic; override with AGENTVISION_OCR_ENGINE=
# tesseract|apple_vision|windows_ocr|rapidocr. See utils/ocr_backends.py.
